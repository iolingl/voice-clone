# 37 音色模型：唱歌音色丢失的诊断（2026-11-16）

## 一句话结论

模型不是"训练轮数不够"或"推理参数没调好"。问题在 **训练域**：37.1 分钟素材全是游戏语音，而且带音乐/音效残留；RVC 的声码器在唱歌时会退回到训练集的平均音质（CPP≈0.25），把 37 本人干净、周期性强、略压紧的歌声（CPP 0.41）磨成气声、发闷、发散的音色。用她自己的 EP 歌声做"自转换"，音质照样掉：CPP 0.413→0.243，H1-H2 1.0→2.9 dB。

## 关键测量

CPP = 倒谱峰突出度（越高越"实"、越有芯）；H1-H2 = 第一/第二谐波差（越高越气声）；LTAS 以 800–1600 Hz 为 0 dB。

模型把所有音区都压到 0.14–0.24，等于把源人声的"芯"换成了训练集的平均音质；不是某个音区单独出问题。

## 五条原因（按重要性）

1. **训练集音质本身就是"散"的。**
   p1 的 CPP 只有 0.220，125–250 Hz 比 p2 高 29 dB，基本可以确定残留了音乐/音效。p2 干净一些（0.286），但离 37 最干净的参考（0.329）和 EP 歌唱（0.413）仍有距离。模型输出的 CPP（0.243–0.277）几乎正好落在训练集 0.254 附近，说明它在复现训练集的平均音质，而不是复现 37 的真实音质。

2. **训练集里没有歌声。**
   37.1 分钟全是短句语音，没有长音、颤音、胸声/混声、belting。RVC 的 HuBERT 内容特征和声码器在长音上没见过对应数据，只能生成"语音化的长音"：气声多、谐波被抹平、发闷。

3. **音域覆盖不够。**
   训练 F0 p10–p90 是 266–471 Hz。甲乙丙丁的 p10 是 199 Hz，EP 里 37 的低音也到 215 Hz 左右；低音区没有足够数据，F0 跟踪和音质都更差。

4. **索引是语音索引。**
   歌声输入在索引里只能检索到语音帧，会把音色进一步拉向语音。我临时做了"语音 + EP 歌声"的混合索引：EP 自转换的 CPP +0.022、H1-H2 −1.7 dB、与 EP 的相似度 +0.011；但 Twinkle 上几乎无变化（索引内容和歌不匹配）。所以索引只能小修，不能治本。

5. **官方 EP 不是 37 独唱。**
   《37如是说》是 37（Emily Stranges）、苏菲亚（Berkley Silverman）、210（Daniel Henkel）、星锑（Carina Reeves）四个角色的歌。高音区（20–60 s、102–115 s）对 37 语音质心的相似度约 0.83，低音区（61–75 s、115–155 s）只有 0.71，是另一个角色（很可能是 210，男声）。**能用于 37 训练的 37 独唱只有约 53 秒**，不能把整首 EP 直接丢进训练集。

## 试过的补救（按有效性）

| 方案 | 效果 | 结论 |
|---|---|---|
| 调 `index-rate` / `protect` / `f0-method` | 6 组参数下 CPP 都在 0.242–0.272，掉点不变 | 参数不是瓶颈 |
| 混合歌声索引 | EP 自转换 +0.02 CPP；跨歌无效 | 保留作小补丁，不指望治本 |
| 谐波增强后处理 | CPP 0.277→0.527；但 ASR 显示 EP 辅音被破坏 | 实验性，只能轻量用 |
| **Seed-VC 零样本 + EP 歌声参考** | EP 自转换 CPP 0.437、频谱平衡接近原 EP；Twinkle CPP 0.566 vs RVC 0.277，simEP 0.895 vs 0.833 | **最有希望的方向** |
| RVC 用 EP 微调 | 未做；可用 37 独唱仅 53 s，预期有限 | 如果坚持 RVC，可试，但要先清 p1 噪声 |

Seed-VC 的注意点：本地缓存的权重和 config 有 11 个 key 形状不匹配（`estimator.conv1/conv2/...`），输出可用但可能有染色；正式用之前要拿到版本匹配的权重。它的输出也偏"过于谐波"，需要听感确认。

## 建议的下一步

1. **先听 11 个 A/B 文件**（`data/37/diagnostics/`，全部 −16 LUFS 归一化）：
   - 01 EP 原声（37 高音区）
   - 02 RVC 当前
   - 03 RVC + 歌声索引
   - 04 RVC + 谐波增强
   - 05 Seed-VC（语音参考）
   - 06 Seed-VC（EP 歌声参考）
   - 07 Twinkle 源
   - 08 Twinkle RVC 当前
   - 09 Twinkle RVC + 谐波增强
   - 10 Twinkle Seed-VC（语音参考）
   - 11 Twinkle Seed-VC（EP 歌声参考）

2. **如果 06/11 明显更像 37**：唱歌管线改用 Seed-VC（EP 高音区做参考），RVC 继续负责语音。需要先对齐 Seed-VC 权重版本。

3. **如果继续 RVC**：
   - 只用 EP 高音区（37 独唱）做微调，重复采样到 ~15–30 分钟等效；不要用低音区（210）。
   - 清洗 p1：按 CPP/低频占比剔除音乐残留片段；或者先用 p2 训练一版对照。
   - 低音歌建议整体移调（伴奏一起）到 266–471 Hz 范围，而不是只降人声。

4. **不要再做的事**：在整首 EP 上训练、继续微调推理参数、把 4–8 kHz 辅音恢复当成音色修复。
